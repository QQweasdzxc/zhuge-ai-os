About Zhuge AI OS

Zhuge AI OS 是一套以 AI 為核心的工作管理平台，整合 Google 帳號、Google Drive 與 WorkLog，協助使用者建立每日工作流程與知識管理。

為什麼需要 Google Drive 權限

Zhuge AI OS 只在使用者主動授權並透過 Google Picker 明確選取文件後，使用唯讀權限讀取該文件。應用程式不會自動掃描或匯入 Google Drive。

應用程式不會修改或刪除 Google Drive 檔案，也不會將 Google 使用者資料用於廣告、販售或不相關的用途。詳情請參閱隱私權政策。

Google Drive Integration

Zhuge AI OS integrates with Google Drive to help users organize knowledge and analyze documents using AI.

Google Drive files are never accessed automatically.

The application only accesses files explicitly selected and authorized by the user.

Users may revoke Google Drive authorization at any time through their Google Account permissions.

Google Workspace APIs are used only after explicit user authorization.

No background scanning. No automatic file collection. No data selling.

How Zhuge AI OS Works

Google Login→Identity→Dashboard→Choose Workspace→WorkLog→Google Picker→Selected File→Knowledge

Google Drive permission is requested only when the user explicitly starts importing files into Knowledge. No background scanning or automatic synchronization occurs.

English summary

Zhuge AI OS is an AI work companion that helps users complete WorkLogs and learn from user-provided work documents. With explicit authorization, it uses read-only Google Drive access to read only the individual files explicitly selected by the user. Google user data is used only for visible, user-facing work assistance features.
