# Multica Native Lab

Purpose: run a near-native Multica self-host inside the Zhuge AI OS Lab boundary so the PM can evaluate human/agent collaboration before any Zhuge Board 2.0 adoption work.

## Upstream freeze

- Repository: https://github.com/multica-ai/multica
- Commit: `8db6cfe19ae6fd5c35ec71bd8fea42a3ef3861ec`
- Upstream license and attribution remain intact.

## Zhuge-owned boundaries

- Human Identity Authority: Zhuge Supabase Auth. Multica does not create a second human account.
- Human UUID: the existing Zhuge / Supabase user UUID is reused as Multica `user.id`.
- Database: Supabase PostgreSQL, isolated in `lab_multica` from Zhuge canonical tables.
- Canonical Lab row UUIDs: generated by the Zhuge Lab UUID authority override.
- Workspace provisioning: Zhuge-owned; native workspace creation / leave / delete are disabled.
- Human membership: Zhuge-owned; native invitations and share-link joining are disabled.
- Runtime: Zhuge-owned machines / cloud runtimes.
- Coding providers: Zhuge-owned Codex / Claude credentials.
- Repository under test: Zhuge-controlled Lab worktree/repository.
- Telemetry: disabled.
- Production credentials and canonical main writes are forbidden in Lab.

## Native behavior intentionally preserved

Issues, Agents, Runs, Runtime coordination, comments, mentions, projects, squads, skills, blockers, retry behavior, usage and Autopilot remain Multica-native for the first experience phase.

The house-rule overlay changes only the parts that would make Multica behave like a separate SaaS tenant: human signup/login, commercial landing CTAs, human membership administration, destructive workspace ownership actions and upstream promotional surfaces.

## Deployment

Render builds use:
- `labs/multica/Dockerfile.backend`
- `labs/multica/Dockerfile.web`

Each build clones the frozen upstream commit, then applies:
1. Zhuge canonical UUID override.
2. Zhuge identity bridge.
3. Zhuge Lab house rules.

The patchers fail closed when an expected upstream marker changes, so an upstream upgrade cannot silently bypass the Zhuge boundary.
