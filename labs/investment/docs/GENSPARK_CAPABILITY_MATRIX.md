## Status meanings

- `READY`: the feature has an implemented UI/domain/provider contract and a
  local test path. This does not claim Production deployment or live provider
  availability.
- `SECRET_REQUIRED`: an optional provider/delivery operation needs a server
  secret or paid account. The surrounding capability implementation can still
  be READY.
- `PENDING`: Production Runtime has not been verified for this local Source.
- `FINAL_AUTHENTICATED_PRODUCTION_ACCEPTANCE`: final user acceptance after a
  reviewed deployment; it must not block local implementation.
- `NONE`: no human gate is identified for this capability.

### Additional implemented observations in this cycle

- Taiwan chip-cycle display joins 20 valid, dated OHLCV sessions with a
  complete five-source-session three-institution total. It reports transparent
  range/trend candidates, a versioned rule, and the underlying values. It is
  explicitly not a confirmed classical Wyckoff phase or trade signal.
- Technical pattern observations check single-candle body/shadow ratios,
  two-candle engulfing/mother-child/piercing/dark-cloud/inside/outside
  relationships, and three-candle morning/evening-star plus consecutive-body
  shapes. These are deterministic descriptive conditions, not forecasts;
  zero-range or malformed OHLC is kept insufficient. This is a tested,
  explainable Zhuge implementation of the feature behavior; it does not copy
  upstream source or claim byte-for-byte algorithm identity.
- The authenticated Taiwan Market projection now includes both TWSE and TPEx
  institutional totals, plus separately dated TWSE / TPEx margin and short
  balances. It deduplicates symbol rows and withholds a venue total if required
  values are incomplete or duplicate rows appear. It never combines venues or
  reports an incomplete sum as a complete market total.
- TDCC has two clearly separated paths: the browser may retain source-dated
  level 13–15 observations as local observations, while the Zhuge scheduled
  publisher merges official dataset 11452 snapshots into a dated normalized
  history artifact for the read-only Edge adapter. The scheduled publication
  has not yet run for this working-tree Source, so published history availability
  remains pending; neither path infers holder identity or buy/sell direction.
- US issuer filing evidence uses SEC `submissions` after SEC ticker-to-CIK
  resolution, before RSS fallback. It does not claim filings are a complete
  news service.
- Official U.S. Treasury daily context is exposed as dated 2Y/10Y/30Y par yields
  and a same-row 10Y−2Y spread. It reuses the shared provider cache and keeps
  its data timestamp, retrieval timestamp, delayed flag, fallback state, and
  official source attribution.
- Fixed FRED market-index (S&P 500, Nasdaq Composite, VIX, Nikkei 225) and H.10
  currency series are read through the authenticated existing Investment
  Intelligence Edge. The adapter accepts no user-supplied URL, requests only a
  bounded recent observation window, and preserves the latest/previous source
  dates, delta, delayed state and freshness. Local provider/UI tests use
  explicit fixtures; signed-in Production readback remains unverified.
- The existing authenticated Investment Intelligence read Edge also requests
  SOX, TSM ADR, and the Korea Composite Index through the Zhuge-owned,
  symbol-bounded Yahoo-compatible adapter. Each observation keeps provider,
  source value/date, fetch time, delayed state, and freshness. These are global
  context references, not a live consolidated quote or trade signal.
- TPEx per-symbol historical bars use its fixed official website endpoint with
  bounded six-month requests. Source transaction volume is in lots and is
  normalized to shares; fixed-price trades are excluded by that historical
  endpoint. Local parser and Edge wiring are covered by tests; authenticated
  Production response remains unverified.
- World Bank Pink Sheet monthly Brent/WTI/Copper is fetched server-side through
  the existing authenticated read Edge after browser CORS blocked its official
  workbook. Lab and Edge share one parser; the response retains CC BY 4.0
  attribution, month, retrieval time, fallback state, and delayed semantics.

## Current verification boundary

Local Lab unit/provider tests and the anonymous desktop/mobile browser journey
verify code contracts and fail-closed access. The browser run does not contain a
signed-in Production user and cannot prove real holdings, watchlist, history,
TWSE/TPEx/SEC results, or US quote availability. The changed Edge Function
source has not been deployed or read back in Production. Therefore this matrix
is an implementation/readiness inventory, not a declaration of 100% capability
parity or Production release acceptance.
