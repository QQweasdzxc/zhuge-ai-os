ABOUT ZHUGE AI OS

About Zhuge AI OS

Zhuge AI OS is an AI-powered productivity platform.

Users sign in once using their Google Account. After authentication, they can access multiple workspaces, including WorkLog, Investment, Travel, HR and future AI modules.

Google Login is used only for authentication. Google Drive access is requested only when users explicitly select files.

  • No background scanning.
  • No automatic file collection.
  • No data selling.
