How Google Data Is Used

Zhuge AI OS follows Google's API Services User Data Policy.

Google Login

Google Account data is used only for user authentication, account identity, and session continuity.

Google Drive

Files are accessed only after explicit user authorization.

Only files selected by the user through Google Picker are processed.

Google Drive files are never accessed automatically, scanned in the background, or shared with third parties.

Google user data is not sold.

Revoking Access

Users may revoke Google authorization at any time through their Google Account permissions. After revocation, Drive features that require authorization may stop working.
