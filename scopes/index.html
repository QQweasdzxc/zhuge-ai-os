GOOGLE OAUTH SCOPES

Google OAuth Scopes

This page explains why Zhuge AI OS requests Google permissions and how users control them.

Google Sign-In

Requested OAuth Scopes

ScopePurpose
openidAuthenticate user identity
emailDisplay signed-in account
profileDisplay user profile
drive.readonlyRead only files explicitly selected through Google Picker

Only files explicitly selected by the user are accessed.

Zhuge AI OS never scans Google Drive. No automatic synchronization. No modification. No deletion.

Collected Data

  • Google ID
  • Name
  • Email
  • Selected file metadata and content needed for the user-requested Knowledge workflow

Not Collected

  • No background scanning
  • No automatic Drive crawling
  • No advertising profiles
  • No data selling
  • No AI model training unrelated to the user-facing product

User Control

Users may grant permission, revoke permission from their Google Account, delete their Zhuge AI OS data, or request deletion through Support.
